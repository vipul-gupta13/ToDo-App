"# Todo List App\n\nA simple todo list web application built with Flask and SQLite.\n\n## Features\n* Add tasks to the todo list\n* View all tasks in the list\n* Delete tasks from the list\n\n## Installation\nTo install the application, follow these steps:\n1. Create a virtual environment: `python -m venv venv`\n2. Activate the virtual environment: `source venv/bin/activate` (on Linux/Mac) or `venv\Scripts\activate` (on Windows)\n3. Install the dependencies: `pip install -r requirements.txt`\n\n## Running the App\nTo run the application, use the following command: `python app.py` or `flask run`\n\n## Screenshots\nAdd screenshots of the application in the `screenshots` directory.\n\n## License\nThis project is licensed under the MIT License.
